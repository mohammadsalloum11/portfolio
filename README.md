# Mohammad Salloum - Portfolio

Personal portfolio site built with plain HTML, CSS and JavaScript (no build step).

## Run locally

```bash
cd "javascript website"
python3 -m http.server 8080
# open http://localhost:8080
```

## Structure

- `javascript website/index.html` - page markup
- `javascript website/css/style.css` - styles and light/dark theme tokens
- `javascript website/java script/script.js` - theme toggle, tabs, contact form
- `javascript website/assets/images/` - images and icons

The contact form has no backend: it opens the visitor's email app with the message pre-filled.
